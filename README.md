## 🌐 Cómo Visualizar el Portafolio

### Opción 1: Abrir Directamente en Navegador (Más Fácil)

1. **Descarga el archivo** `portfolio_julian_juarez.html`
2. **Haz doble clic** en el archivo
3. Se abrirá automáticamente en tu navegador predeterminado

### Opción 2: Servidor Local (Recomendado para Desarrollo)

Si deseas probar funcionalidades avanzadas o hacer modificaciones:

```bash
# Opción A: Python Simple HTTP Server
python -m http.server 8000

# Opción B: Node.js http-server
npx http-server

# Opción C: PHP Built-in Server
php -S localhost:8000
```

Luego abre tu navegador en: `http://localhost:8000/portfolio_julian_juarez.html`

### Opción 3: Publicar en GitHub Pages

1. Crea un repositorio en GitHub
2. Sube el archivo `portfolio_julian_juarez.html` (renómbralo a `index.html`)
3. Activa GitHub Pages en Settings → Pages
4. Tu portafolio estará disponible en: `https://tu-usuario.github.io/tu-repo/`

## 🐛 Troubleshooting

### El portafolio no se ve bien en mi navegador

**Solución**: Asegúrate de usar un navegador moderno:
- Chrome 90+
- Firefox 88+
- Safari 14+
- Edge 90+

### Las animaciones no funcionan

**Solución**: Verifica que JavaScript esté habilitado en tu navegador.

### El formulario de contacto no envía datos

**Solución**: El formulario actual es un ejemplo. Para funcionalidad completa:
- Implementa backend (Node.js, Python Flask, PHP)
- O usa servicios como Formspree, EmailJS, etc.
